# GCH Public Marketing — 35-Journey Wireframe Implementation Matrix

Status: planning baseline for coded wireframes.

## Brand implementation rules

- Public marketing surfaces default to Cream `#F8F5EF`, Cream Dim `#EDE9E2`, and White; technical/product moments may transition to Brand `#0B0D12`, Default `#1E2028`, and Elevated `#2E3347`.
- GCH Gold is the primary agency accent. Ministry Blue is reserved for ministry, connection, support, GLinks, and communication contexts. Sacred Ember is an energy/highlight treatment, not a default page fill.
- **JetBrains Mono is the visitor cue face**: use it for journey IDs, eyebrows, micro-labels, status chips, filter labels, navigation indicators, blueprint annotations, small CTA cues, and other short visual indicators. Do not use it for paragraphs. Outfit remains the body face. Space Mono remains reserved for numeric HUD/readout data where numbers need a separate visual role.
- Photography should emphasize contemporary Christian ministry and mission contexts: worship, prayer, open Bibles, Bible study, church services, streaming/production setups, online Bible study, ministry/business meetings, church leadership, volunteers, nonprofit work, and Christian business. Avoid Catholic-specific iconography or visual language that would misrepresent the intended brand context.
- Motion must support hierarchy and comprehension. All scroll/parallax experiences require a reduced-motion equivalent.

## Definition of done for each coded wireframe

Each journey is ready to leave wireframe status only when it has: desktop + tablet + mobile behavior; real semantic structure; keyboard path; reduced-motion path; light/dark/accent token usage; JetBrains Mono cue usage; approved image/video brief and POV; a real CTA destination or explicit placeholder contract; and documented dependencies on shared primitives.
